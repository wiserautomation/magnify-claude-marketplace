# Supervised Google Ads optimization

Discover the store and supported Magnify capabilities. Start with read-only evidence and propose a bounded change, including exact campaign/ad group/product identifiers, preconditions, expected impact, risks and rollback approach. Use the registered preview/preparation tools where available. Never claim a tool exists without discovering it. Require explicit, informed user approval through the actual host's supported consent flow before execution. Do not replace a real approval with conversational assumptions or bypass server-side permissions. After execution, request read-after-write verification and report the exact confirmed result. If approval is external in this client, describe that limitation; never simulate an in-chat approval. Avoid bulk or irreversible actions unless the user explicitly authorized their exact scope.
