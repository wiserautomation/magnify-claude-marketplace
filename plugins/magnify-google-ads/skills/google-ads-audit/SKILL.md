# Audit Google Ads with Magnify

Use Magnify MCP tools to discover authorized stores, select the user's intended account, and obtain account health and performance for the requested date window. For campaign, search term, keyword, and conversion diagnostics, call only available authorized read tools. Never invent account metrics or imply a report was fetched when a tool failed. Distinguish observed results, data limitations, and recommendations. Rank opportunities by supported spend/CPA/ROAS evidence and likely business impact. Treat conversion actions as qualified only when verified; ask about offline lead quality if needed. Provide specific recommended next actions, but perform no changes during an audit. Do not expose authentication tokens or cross-store information.
